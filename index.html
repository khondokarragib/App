The Golden Egg Rules

The The Golden Egg video slot is referred to as Golden Egg, The Game or Game.

Golden Egg is a Video Bingo game with 1 card. The features of this game are: Turbo and New Card.

The game is played with 1 card with 15 numbers on it. First column in the card will display numbers only between 1 and 9 value, second column will display only 10-19, third column will display only 20-29, fourth column will display only 30-39, fifth column will display only 40-49, sixth column will display only 50-59, seventh column will display only 60-69, eighth column will display only 70-79 and last column will display only 80-90.

90 balls numbered 1-90 are randomly drawn in each round until 15 numbers matched in a card.

Number of balls called will be displayed under "Balls Called" in the panel screen.

Card numbers are highlighted with red color on the panel board. Unmatching drawn numbers are highlighted in black color on the panel board. Any numbers on the played card that match those drawn from the machine will be highlighted with white color.

Select a stake to play. Change the numbers on the card using the "New Card" button and click "Play" to start to draw.

The game can be played faster by pressing the "Turbo" button. Once turbo button is activated it cannot be deactivated for the current game round.

The game can be played even faster by pressing the "Instant" (forward icon) button when game is started. Once clicked on "Instant" button, displaying the number of each draw is skipped. Total numbers drawn are displayed in "Balls Called" field. Each drawn number will be highlighted in panel screen (1-90) and win amount will be displayed in pop-up message (if occurs). Once all 15 numbers have been highlighted, wins will be displayed. The top payout will be awarded if the card is complete.
